# Industrial Sales Operations Analytics

An end-to-end industrial distribution analytics portfolio project combining synthetic ERP data, PostgreSQL, Python, geographic territory optimization, and Power BI.

## Project Overview

This project simulates sales operations for a fictional U.S. industrial distributor.

The objective is to demonstrate how transactional sales data can be transformed into reliable reporting, customer and product insights, and geographically informed sales territory assignments.

All business, customer, employee, and transaction data is synthetic. Geographic reference data will come from documented public sources.

## Technology Stack

- **Development OS:** Fedora Linux
- **IDE:** Visual Studio Code
- **Programming:** Python 3.12
- **Database:** PostgreSQL 18
- **SQL Development:** DBeaver
- **Analysis:** pandas, NumPy, SciPy, scikit-learn, JupyterLab
- **Reporting:** Microsoft Power BI Desktop (Windows VM)
- **Version Control:** Git and GitHub

## Project Scope

- Synthetic ERP transaction generation
- Data ingestion, cleaning, and reconciliation
- PostgreSQL analytical data modeling
- ZIP-based sales territory optimization
- Customer and product performance analysis
- Power BI dashboards and role-level security demonstration

## Project Status

In development.

## Data Privacy

This is an independent portfolio project. It does not use confidential employer data, internal business rules, or proprietary source files.

## Reproducibility

Development is performed primarily on Fedora Linux, with workflows designed to remain portable across operating systems. Setup instructions, data generation scripts, SQL definitions, and validation procedures will be documented as development progresses.
